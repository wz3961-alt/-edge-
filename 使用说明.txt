必应海外版守卫 1.2.5

新标签页：必应搜索和输入建议；可添加、删除快捷方式；可选城市天气；每次打开轮换背景。默认天气城市为长春（可在右下角设置中修改）；点击右上角天气可打开 Open-Meteo 页面，并带上所选城市坐标。快捷方式提供必应、bilibili、ChatGPT 和 GitHub 示例，截图中其他网站的准确网址无法从图片确定，请自行添加。

在 edge://extensions 中停用旧副本，启用开发人员模式，加载本文件夹。若已加载本文件夹，在扩展管理页面重新加载。打开新标签页进行检查。如果 Edge 提示扩展更改新标签页或默认搜索，请按需保留。不要同时启用多个副本。

背景随机显示世界各地的 Wikimedia Commons 风景照片，优先避免连续使用同一张；网络不可用时显示提示和内置颜色背景。图片介绍含作者和授权链接。搜索建议由必应提供，输入的内容会发送给必应以获取建议。天气和城市搜索由 Open-Meteo 提供，发送所选城市名称或坐标；不自动读取设备位置。快捷方式及城市保存在扩展本地存储中，移除扩展可能丢失。

本扩展仍保留原必应守卫：默认将必应及 MSN 流量通过本机 HTTP 代理 127.0.0.1:7897，失败不回退直连；其他域名走 DIRECT，不继承系统 HTTP 代理。请在扩展按钮中核对代理端口；要撤销全部设置，请停用或移除扩展。美国地区设置和本地代理不保证真实出口或所有结果为美国版。

当前包尚未在此 Edge 配置中实测加载，搜索建议、天气、图片能否连接取决于网络和服务端状态；建议不可用时仍可手动搜索。

1.2.1：修复直接打开文件时因扩展存储不可用导致的页面初始化失败。普通文件页面在不同浏览器中受跨域规则约束，天气、搜索建议和在线背景可能仍无法联网；优先使用扩展的新标签页。

1.2.2：背景轮换世界各地的 Wikimedia Commons 风景照片，底部显示地点、介绍、作者和授权链接。需要网络访问图片服务；无法加载时显示提示与内置渐变。

1.2.3：右下角设置新增“打开扩展管理”按钮。普通文件预览不具备扩展权限，会提示手动输入管理页地址。

1.2.4：点击右上角天气可跳转到当前城市的必应天气搜索；城市选择仍在右下角设置。

1.2.5：天气按钮跳转至 Open-Meteo 页面，并携带当前城市坐标及当前天气项目。
